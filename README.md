Premier clavier complet pour la langue Zarma (Niger, Mali, Burkina) avec toutes les lettres : ã ẽ ĩ õ ũ ŋ ɲ


Fonctionnalités
- Lettres Zarma : ã, ẽ, ĩ, õ, ũ, ŋ, ɲ
- Dictionnaire Zarma intégré
- Fonctionne dans WhatsApp, Facebook, TikTok
- Gratuit et open source

Fait à Lomé pour préserver notre langue.
Pourquoi ce clavier ?

Le Zarma est parlé par plus de 5 millions de personnes au Niger, Mali, Burkina. Mais aucun clavier ne permet d'écrire correctement ã ẽ ĩ õ ũ.

Ce clavier résout ce problème.
 Lettres incluses
a -> ã
e -> ẽ
i -> ĩ
o -> õ
u -> ũ
n -> ŋ et ɲ

Appui long sur la lettre pour avoir la variante.
